# Nagaraj's Portfolio

A modern, responsive portfolio website built with React and Tailwind CSS featuring a dark/neon theme with smooth animations.

## 🚀 Features

- **Modern Design**: Dark theme with neon accents and glass morphism effects
- **Responsive**: Fully responsive design that works on all devices
- **Animations**: Smooth animations using Framer Motion
- **Interactive**: Hover effects and interactive elements
- **Fast**: Optimized for performance

## 🛠️ Tech Stack

- React 18
- Tailwind CSS
- Framer Motion
- React Icons
- React Intersection Observer

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/Nagaraj0000b/portfolio.git
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

## 🚀 Deployment to GitHub Pages

1. Install gh-pages (if not already installed):
```bash
npm install --save-dev gh-pages
```

2. Build and deploy:
```bash
npm run deploy
```

3. Your portfolio will be available at: `https://nagaraj0000b.github.io/portfolio`

## 🎨 Customization

To customize the portfolio:

1. Update personal information in the components
2. Modify colors in `tailwind.config.js`
3. Add/remove sections as needed
4. Update project information in `Projects.js`

## 📱 Sections

- **Hero**: Introduction with animated name and social links
- **About**: Personal information and quick facts
- **Skills**: Technical skills organized by category
- **Projects**: Featured projects with live demos
- **Education**: Academic background and certifications
- **Contact**: Contact form and information
